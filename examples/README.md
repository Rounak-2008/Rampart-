## How to Run the Example Suite

To execute all 4 examples against the real RAMPART analysis engine and compare actual outputs against expectations:

```bash
# From the project root:
PYTHONPATH=backend python3 examples/run_examples.py
```

### What `run_examples.py` Executes:
1. Initializes or connects to the local SQLite database (`rampart.db`) in WAL mode.
2. Ensures the benchmark evaluation repository (`acme-org/rampart-core`) exists.
3. Inserts each synthetic pull request and contributor profile with deterministic metrics.
4. Invokes `analyze_pull_request` using `files_override` with the exact diff hunks.
5. Employs local Ollama `gemma4:e4b` (or transparent deterministic fallback if offline).
6. Compares actual quality, risk, priority decision, and AI recommendation against expected benchmarks.
7. Saves the structured JSON output into `examples/<id>/actual_output.json`.
8. Prints a pass/fail verification summary table.

## Maintainer Sovereignty Principle

RAMPART's AI reviews are strictly advisory. Final merge, request changes, or closure decisions remain entirely under human maintainer sovereignty.
